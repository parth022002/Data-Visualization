# Data Dictionary — Tableau Masterclass Reference Datasets

## Reference Datasets (`Data/raw/`)
1. **`small-dataset/`**:
   - `Orders.csv`: Core sample transactional records.
   - `Customers.csv`: Customer account demographics.
   - `Products.csv`: Product SKUs, categories, and subcategories.
   - `LOD.csv`: Granular dataset specifically designed to teach Level of Detail calculations.
2. **`big-dataset/`**:
   - High-volume transaction datasets for testing extract performance, large table calculations, and aggregation speeds.
