# Data Dictionary — Workforce Analytics

| Field | Type | Description |
| :--- | :--- | :--- |
| `Employee_ID` | String | Unique employee identifier |
| `First Name` | String | Given name |
| `Last Name` | String | Family name |
| `Gender` | String | Gender classification |
| `State` | String | Work location state |
| `City` | String | Work location city |
| `Education Level` | String | Educational attainment |
| `Birthdate` | Date | Date of birth (YYYY-MM-DD) |
| `Hiredate` | Date | Onboarding date (YYYY-MM-DD) |
| `Termdate` | Date | Termination date (null if currently active) |
| `Department` | String | Business department |
| `Job Title` | String | Functional role title |
| `Salary` | Numeric | Annual base salary in USD |
| `Performance Rating` | Integer | Evaluation score (1-5) |
| `Is_Active` | Integer | Active indicator (1=Active, 0=Terminated) |
| `Attrition_Status` | String | Status label (Active / Terminated) |
