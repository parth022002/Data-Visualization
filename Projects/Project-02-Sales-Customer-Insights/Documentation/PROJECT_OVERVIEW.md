# Project Overview — Executive Sales & Customer Insights

## Context & Vision
Commercial executives require immediate visibility into product margin health, discount leakages, customer lifetime retention, and territorial trends. This project synthesizes raw transactional feeds into an intuitive executive briefing room.

## Technical Highlights
1. **Unified Schema:** Built an ingestion bridge converting European semicolon-and-comma formatted CSVs and standard dot-decimal CSVs into a standardized UTF-8 pipeline.
2. **Dynamic UI:** Integrated custom collapsible filter menus, synchronized page navigation, and consistent typographic hierarchies.
3. **Rigorous Financial Math:** 33 calculated fields enforcing standard GAAP margin and discount calculations.
